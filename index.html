How it works

  • Type each octet. Press ., / or Space to jump to the next box. A box also advances after three digits.
  • Press Enter to go Check all → Show all → Next problem.
  • A problem counts as solved when all five rows are right without using Show.
  • Auto-fill copies in every octet except the interesting one, so you can drill the block-size step alone.
